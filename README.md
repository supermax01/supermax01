# Chandra Vikram

Healthcare AI engineer. I build and evaluate AI systems for clinical care: retrieval-augmented and fine-tuned language models, benchmarks that pin claims to published baselines, and the HL7 FHIR plumbing that gets model output back into the record.

MS in Health Informatics, Indiana University Indianapolis. Pharmaceutical sciences before that.

- [TPN-RAG](https://github.com/Supermax101/TPN-RAG-Public) — clinical-nutrition RAG benchmark: 5 LLMs x 5 prompting strategies, hybrid retrieval, NLI citation grounding

- [hapi_flutter](https://github.com/supermax01/hapi_flutter) — FHIR Patient/$everything demo against a HAPI FHIR server
- [Clinical Frontier](https://chandravikram.com) — working notebook of 18 preliminary manuscripts on clinical AI
